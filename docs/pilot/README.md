# 中2数学 v1 実利用パイロット（1〜2週間）

シミュレーションではなく、実際に1人の中学2年生が使ったときの
続けやすさ・分かりやすさ・学習量・診断の納得感・今日の学習の実用性・保護者画面の分かりやすさを確かめる。

## 対象の版

- tag `middle-school-math-v1`（commit `42e1f276552ba74a17f1a654faa76573a4cd66ad`）＝中2数学 v1
- パイロットは branch `pilot-v1` で動かす（v1 ＋ 記録用ページ ＋ パイロット中の「すぐ直す」修正だけ）
- 公開版（main）は使わない・push しない（11月まで凍結）

## はじめる前に（1回だけ）

1. パイロット用の PC で `node serve.js` を起動する
2. 子どもが使う端末で開く
   - 同じ PC なら `http://localhost:5178/`
   - タブレット・スマホなら `http://<PCのIPアドレス>:5178/`（同じ Wi-Fi）
3. `http://.../?debug=pilot` を開き、「パイロットを始める」を押す
   - ふだんの画面の右下に「メモ」ボタンが出る
4. 子どもと一緒に、最初のコンパスチェックと「学校のようす」を入れる

- 記録はその端末のブラウザに残る。期間中は**同じ端末・同じブラウザ**で使う
- シークレットウィンドウは使わない（記録が消える）

## 毎日やること

- 子ども：ホームの「今日の学習」をする（時間はふだんの設定のまま）
- 迷った・面倒・「なぜ？」のときは、その場で右下の「メモ」を押して一言書く（保護者が押してもよい）
- 保護者：1日の終わりに `?debug=pilot` を開き、その日の欄を5分で書く
  - 自動で入るもの：日付・学校の進度・学習可能時間・提案した内容・実際に解いた内容・チェック・まちがえた問題・その場のメモ
  - 書くもの：迷った画面・面倒そうだった操作・「なぜこれをやるの？」・簡単すぎる／難しすぎる問題・診断結果への違和感・保護者から見た違和感・そのほか
  - 書くことがない日は空欄でよい
- 「見つけたこと」に、直す候補を1行ずつ足す（分類を選ぶ）
- 1日の終わりに「記録を書き出す（JSON）」で控えを保存する（端末の不調に備える）

## 修正ルール

パイロット中は、見つけたものをすぐ全部は直さない。

### すぐ直す（パイロット中に直す）

- 学習できない
- データが壊れる
- 明らかに間違った問題
- 学習判断が大きく誤る

### あとでまとめて判断（パイロット後）

- 表現
- ボタン名
- 画面の長さ
- 時間配分の小さな違和感
- 問題数不足

- すぐ直したものは `pilot-v1` にコミットし、「見つけたこと」の状態を「直した」にする
- 直したことで子どもの記録は消さない（記録の形を変える修正はしない）

## 終わったら

1. `?debug=pilot` の「記録を書き出す（Markdown）」と「（JSON）」を保存する
2. [report-template.md](report-template.md) の形でまとめる
