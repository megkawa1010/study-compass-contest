# Study Compass（コンテスト版）

「わからない」を越えて、自分の可能性へ。

短いチェックで「現在地」を知り、つまずきの原因を探して、今日やることを1つに絞る学習支援Webアプリのデモです。
今回は **中学2年・数学「一次関数」** だけをモデルケースとして収録しています。

**公開URL：https://megkawa1010.github.io/study-compass-contest/**

- ログイン不要・個人情報の入力なし
- HTML / CSS / JavaScript だけで動く（ビルド・サーバー処理・外部API なし）
- 記録はその端末のブラウザ（localStorage）にだけ保存

## AIの使用について（正直な現状）

このデモの診断は **ルールベース** です。
各問題に「確認するスキル」と「前提知識」を持たせ、基礎問題の結果から原因確認問題を選び、その結果の組み合わせでつまずき候補を推定しています。
**外部のAI（生成AI API）は、このデモでは使っていません。** 将来、結果文の生成や問題の自動作成にAIを使う想定の設計です。

## 画面の流れ

1. ホーム → 2. 初期設定（学年・教科・単元・学習状況）
3. コンパスチェック（基礎5問・1画面1問・ヒント/わからない付き）
4. 追加確認（**回答によって出す問題が変わる**。原因確認 C1〜C5 / 標準 S1・S2）
5. 現在地（ルートマップ・できているところ・もう少し確認したいところ・今越えたいところ・発見）
6. 今日の学習（25分・3ステップ。解説→練習→チェックで止まった問題に再挑戦）
7. 振り返り（😊🤔😣 → 記録・現在地の更新）

基礎・標準がすべてできた場合は、応用（料金プランの文章題 A1）を「Aの式 → Bの式 → 方程式と答え」の3ステップで学習します。

## 学習データ（Phase 1）

保存キー `study-compass/v2`（localStorage）に、次の形で持ちます。

- `answer_history[]` … 回答1件ごとの記録（上書きしない）
  `id, user_id, session_id, context(compass_check|lesson), question_id, unit, skill, level, correct, hint_used, unknown_selected, answered_at, self_evaluation`
- `sessions[]` … コンパスチェック1回分（出した問題・今日越えること・つまずき候補・その時点の確かさの控え・ふり返り）
- `skill_state{}` … スキルごとの現在地。**保存値を足し引きせず、毎回 answer_history 全体から計算し直す**
  `learning_status（未学習/学習中/要確認/理解/活用/定着）, basic/standard/application/retention（not_checked/pass/needs_review）, confidence, attempt_count, correct_count, suspected_root_causes, last_checked, next_action`
- `profile.school_progress` … 単元ごとの「習った / 習っている途中 / まだ習っていない」
- `user_id` は端末内で作る匿名ID（個人情報は持たない）

確かさ（confidence）の考え方（調整値は `js/engine.js` の `CONFIG`）

- 上限は「どのレベルまでできたか」で決まる：基礎 0.50 / 標準 0.65 / 応用 0.80、数日後もできたら +0.12（2回目で +0.15、最大 0.95）
- その中で、最近の結果を重めに見る（ヒントありの正解は半分、練習はチェックの半分の重さ）
- 1回の回答で下がるのは最大 0.15。最初に「できた」日から3日以上あとに自力でできたら「定着」
- レベルの判定は直近3回を新しいものほど重く見る（1回の×で取り消さない）
- まだ習っていない単元のスキルは、できなくても「要確認」ではなく「未学習」
- つまずき候補は、前提スキルをたどって一番根元の「まだ不安定なスキル」を挙げる

コンテスト版（v1）の記録は、初回に読み込んで履歴に移します（v1 のデータは消しません）。

## 問題バンク

全70問（既存12問＋追加58問）。一覧は `?debug=bank` で図・答え・解説つきで確認できます。

| スキル | 基礎 | 標準 | 応用 | 定着 | 計 |
|---|---|---|---|---|---|
| 変化量・式への代入・変化の割合・傾き切片・グラフ式（一次関数） | 3 | 3 | 2 | 2 | 各10 |
| 正負の数・文字式への代入・比例・座標（既習） | 3 | − | − | 2 | 各5 |

- 形式（format）：数式・表・グラフ・文章・数直線。一次関数の各スキルは3種類以上の形で出題
- 答えの種類（type）：number / linear / pair / choice / steps
- 応用問題（steps）は小問に分け、小問ごとに skill を持つ。`logic.analyzeSteps` で「どの小問で止まったか」と、そのスキルを原因候補として返す
- 定着用の問題（retention）は evidence_level（基礎相当・標準相当）を持つ。定着になるかは問題の種類でなく、最初にできた日から3日以上たってからの正解で決まる
- `SC.bank.pick(skill, level, { history, exclude, rng })` … 未出題を優先し、なければ一番前に解いた問題。同じ優先度からはランダム。`SC.bank.seeded(n)` で乱数を固定できる
- 既存の B1〜B5 / C1〜C5 / S1・S2 とコンパスチェックの流れは変更なし。バンクの問題を実際に出すのは Phase 2 から
- `tests/bank.test.js` で、必須項目・自分の答えで正解になるか・グラフの点が直線上にあるか・表が一次関数になっているか・定着問題が他と重なりすぎないか を機械的に確認

## 定期コンパスチェック（Phase 2）

1回の診断で決めつけず、記録を見ながら「今、確かめ直した方がよいスキル」を選んで、問題バンクから前回と違う問題を出す。調整値は `js/compass.js` の `CONFIG`。

- **発生条件**（どちらか）：そのスキルを最後にチェックしてから `COMPASS_CHECK_DAYS`＝3日 ／ 前回のチェック後に `COMPASS_CHECK_MIN_ATTEMPTS`＝5問練習
- **優先度**：1 確かさ 0.65 未満 → 2 標準・応用に要確認 → 3 一度できたが定着が未確認 → 4 定着していたが14日以上あいた → 5 直近4回で2回以上まちがい（最後も×）
- **問題数**：1回3〜5問、1スキル2問まで（優先度1・5のスキルに2問目）
- **出題レベル**：基礎が不安定→基礎／基礎OK→標準／標準OK→応用／応用OK→定着（既習スキルは基礎の次に定着）
- **除外**：直近3回のチェックで出た問題と、7日以内に解いた問題。定着を確かめる目的のときは、そのスキルで一度でも解いた問題を出さない。候補がないときだけ条件をゆるめ、その旨を記録する
- **ホーム**：条件を満たしたらお知らせ（今チェックする／今日はあとで）。起動時に強制しない。「今日はあとで」はその日のあいだだけ
- **結果**：スキルごとに前回→今回（◎○△）、上がったスキルは「ひとつ越えました！」、コメント、これまでの記録から見た現在地
- **今日の学習**：チェック後の skill_state から作り直す（前提に近い「まだ不安定」なスキルから。基礎が安定したら標準へ、標準もできたら応用へ）
- **マスター**：基礎・標準・応用・定着すべて pass ＋ 確かさ 0.85 以上。履歴から毎回計算するので、あとの不正解で下がりうる
- **応用問題の小問**：小問ごとに記録（`問題ID#s1`）し、どこで止まったかを残す。理解度の計算では「1問の中の同じスキルの小問」を1回分にまとめ、すべて正解のときだけ正解とする
- **保存**：`compass_check_history[]` … `id, session_id, date, questions, skills, skill_ids, reasons（問題ごとの選んだ理由）, before, after, comment, plan_key, focus_skill`
- **確認用**：`?debug=compass` … 対象スキル・理由・発生条件・出題候補（乱数の種1の例）・除外した問題・これまでのチェックの前後比較

## 起動方法

- いちばん簡単：`index.html` を Chrome にドラッグ＆ドロップ
- ローカルサーバー：`node serve.js` → http://localhost:5178
- テスト：`node --test tests/*.test.js`
- 動作確認用パネル：URLの最後に `?debug=1`（日付を3日進める・記録の書き出し）。ふだんは表示されない
- 記録を消す：ホーム下部「学習の記録について」→「記録をすべて消す」

## 公開方法

静的ファイルだけなので、このフォルダをそのまま置けば公開できます。

- GitHub Pages：リポジトリにこのフォルダの中身を置き、Settings → Pages で main ブランチのルートを公開
- Netlify Drop：https://app.netlify.com/drop にこのフォルダをドラッグ
- Cloudflare Pages：`npx wrangler pages deploy .`

## デモ手順（おすすめ）

1. 「コンパスチェックをはじめる」→「現在地をチェックする」
2. Q1 `-2`、Q2 `6`、Q3 `7` と答える
3. Q4・Q5 は「わからない」を押す
4. 追加確認が2問だけ出る（原因確認：増加量、傾き・切片）
5. 増加量は x `3`・y `5`（あえて違う答え）、傾き・切片は `-3`・`4`
6. 現在地：座標・比例・代入＝できている／変化の割合＝もう少し／グラフ・式＝確認中
7. 「今日の学習を作る」→ 増加量 → 変化の割合 → 一次関数に再挑戦
8. 振り返りで気持ちを選ぶと記録される

右上の「はじめから」でいつでもやり直せます。
