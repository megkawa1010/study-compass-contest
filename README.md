# Study Compass（コンテスト版）

「わからない」を越えて、自分の可能性へ。

短いチェックで「現在地」を知り、つまずきの原因を探して、今日やることを1つに絞る学習支援Webアプリのデモです。
今回は **中学2年・数学「一次関数」** だけをモデルケースとして収録しています。

**公開URL：https://megkawa1010.github.io/study-compass-contest/**

- ログイン不要・個人情報の入力なし
- HTML / CSS / JavaScript だけで動く（ビルド・サーバー処理・外部API なし）
- 記録はその端末のブラウザ（localStorage）にだけ保存

## AIの使用について（正直な現状）

このデモの診断は **ルールベース** です。
各問題に「確認するスキル」と「前提知識」を持たせ、基礎問題の結果から原因確認問題を選び、その結果の組み合わせでつまずき候補を推定しています。
**外部のAI（生成AI API）は、このデモでは使っていません。** 将来、結果文の生成や問題の自動作成にAIを使う想定の設計です。

## 画面の流れ

1. ホーム → 2. 初期設定（学年・教科・単元・学習状況）
3. コンパスチェック（基礎5問・1画面1問・ヒント/わからない付き）
4. 追加確認（**回答によって出す問題が変わる**。原因確認 C1〜C5 / 標準 S1・S2）
5. 現在地（ルートマップ・できているところ・もう少し確認したいところ・今越えたいところ・発見）
6. 今日の学習（25分・3ステップ。解説→練習→チェックで止まった問題に再挑戦）
7. 振り返り（😊🤔😣 → 記録・現在地の更新）

基礎・標準がすべてできた場合は、応用（料金プランの文章題 A1）を「Aの式 → Bの式 → 方程式と答え」の3ステップで学習します。

## ファイル構成

```
index.html        画面の骨組み
css/styles.css    デザイン（スマホ優先・PC対応）
js/questions.js   問題データ（基礎B1〜B5・原因確認C1〜C5・標準S1〜S2）
js/logic.js       採点（表記ゆれ吸収）・分岐・診断・学習プラン
js/app.js         画面遷移・保存・操作
icons/            アイコン
serve.js          ローカル確認用の小さなサーバー（依存なし）
tests/            診断ロジックのテスト
```

## 起動方法

- いちばん簡単：`index.html` を Chrome にドラッグ＆ドロップ
- ローカルサーバー：`node serve.js` → http://localhost:5178
- テスト：`node --test tests/logic.test.js`

## 公開方法

静的ファイルだけなので、このフォルダをそのまま置けば公開できます。

- GitHub Pages：リポジトリにこのフォルダの中身を置き、Settings → Pages で main ブランチのルートを公開
- Netlify Drop：https://app.netlify.com/drop にこのフォルダをドラッグ
- Cloudflare Pages：`npx wrangler pages deploy .`

## デモ手順（おすすめ）

1. 「コンパスチェックをはじめる」→「現在地をチェックする」
2. Q1 `-2`、Q2 `6`、Q3 `7` と答える
3. Q4・Q5 は「わからない」を押す
4. 追加確認が2問だけ出る（原因確認：増加量、傾き・切片）
5. 増加量は x `3`・y `5`（あえて違う答え）、傾き・切片は `-3`・`4`
6. 現在地：座標・比例・代入＝できている／変化の割合＝もう少し／グラフ・式＝確認中
7. 「今日の学習を作る」→ 増加量 → 変化の割合 → 一次関数に再挑戦
8. 振り返りで気持ちを選ぶと記録される

右上の「はじめから」でいつでもやり直せます。
